<h2>Privacy & Security Policy</h2>
<p><strong>Last Updated:</strong> March 2026</p>

<hr>

<h2>1. Introduction</h2>
<p>
VEXA Mining Pro ("VEXA", "we", "our", or "us") is a browser-based Progressive Web App (PWA)
that allows users to simulate digital mining activity.
</p>
<p>
We are committed to protecting your privacy and ensuring the security of your information.
</p>

<h2>2. Information We Collect</h2>

<h3>Account Information</h3>
<ul>
<li>Email address</li>
<li>Encrypted password (secured through Supabase Authentication)</li>
</ul>

<h3>Application Data</h3>
<ul>
<li>Mining balance</li>
<li>Coins mined per day</li>
<li>User level</li>
<li>Upgrade progress</li>
</ul>

<p><strong>We do NOT collect:</strong></p>
<ul>
<li>Banking information</li>
<li>Credit/debit card details</li>
<li>Government ID numbers</li>
<li>Biometric data</li>
</ul>

<h2>3. How Your Data Is Stored</h2>
<p>
User authentication and database storage are handled securely using Supabase services.
</p>
<ul>
<li>Passwords are encrypted and hashed.</li>
<li>We do not have direct access to user passwords.</li>
<li>All communication uses HTTPS encryption.</li>
</ul>

<h2>4. Security Measures</h2>
<p>We implement multiple security measures including:</p>
<ul>
<li>HTTPS secure connections</li>
<li>Row-Level Security (RLS) in the database</li>
<li>Secure authentication using Supabase Auth</li>
<li>Limited frontend API key exposure (anon key only)</li>
<li>Service role keys are never publicly exposed</li>
</ul>

<h2>5. Offline Data Handling</h2>
<p>
When the app is used offline:
</p>
<ul>
<li>Mining data may be temporarily stored in the browser.</li>
<li>Data syncs securely when the internet connection is restored.</li>
<li>No sensitive personal information is permanently stored on the device.</li>
</ul>

<h2>6. Third-Party Services</h2>
<p>VEXA uses the following third-party services:</p>
<ul>
<li>Supabase (Authentication & Database Hosting)</li>
<li>GitHub Pages (Application Hosting)</li>
</ul>
<p>
These services may process limited technical data required for application functionality.
</p>

<h2>7. User Responsibilities</h2>
<p>Users agree to:</p>
<ul>
<li>Provide accurate account information.</li>
<li>Maintain the confidentiality of login credentials.</li>
<li>Not attempt to exploit, hack, or manipulate the system.</li>
</ul>

<h2>8. Data Retention</h2>
<p>
User data is stored as long as the account remains active.
Users may request account deletion at any time.
</p>

<h2>9. No Financial Guarantees</h2>
<p>
VEXA Mining Pro is a simulation-based mining application.
It does not guarantee financial returns, investments, or real-world earnings.
</p>

<h2>10. Changes to This Policy</h2>
<p>
We reserve the right to update this policy.
Updates will be reflected with a new "Last Updated" date.
</p>
